Perjalanan saya di industri teknologi dibangun di atas pemahaman yang kuat tentang bagaimana data bergerak dari infrastruktur fisik terkecil hingga ke sistem jaringan yang kompleks. Saya mempelajari dasar arsitektur jaringan secara mendalam, termasuk teknik instalasi jaringan fiber optik baik skala perumahan (FTTH) maupun korporat/gedung bertingkat (FTTB). Pemahaman ini memberi saya perspektif yang jelas tentang bagaimana data dapat berjalan di lapisan fisik (physical layer).

Tidak berhenti di layer fisik, saya memperluas kompetensi ke ranah System Administration (SysAdmin). Di fase ini, saya mendalami manajemen server, konfigurasi operating system (terutama berbasis Linux dan Windows), serta pengelolaan hak akses dan arsitektur sistem operasi. Menguasai bagaimana server bekerja dan dikelola memberikan saya fondasi penting untuk mengenali sistem secara struktural.

Namun, titik balik terbesar saya adalah ketika saya menyadari bahwa membangun dan mengelola infrastruktur saja tidak cukup jika perimeter tersebut rentan dari serangan. Hal ini mendorong saya untuk mendedikasikan fokus penuh pada sektor Cybersecurity, khususnya di bidang Blue Teaming dan operasi Security Operations Center (SOC).

Bagi saya, kombinasi keahlian dari instalasi jaringan, SysAdmin, hingga taktik pertahanan siber menjadikan saya seorang analis yang versatile. Saya melihat pertahanan siber bukan sekadar membaca dasbor alert, melainkan seni mengorelasikan log data, mengamankan seluruh arsitektur jaringan, serta menutup celah sebelum penyerang sempat mengeksploitasinya.
